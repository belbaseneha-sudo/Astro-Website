# Astro — Astrology Website

Astro is a personal front-end website project that I independently designed and built using HTML, CSS and JavaScript.

The website features a dark, space-inspired design, zodiac-themed content, interactive elements and a responsive layout.

## Project Highlights
- Original dark navy and purple visual design
- Zodiac-themed sections and graphics
- Interactive front-end elements
- Responsive desktop and mobile layouts

## Technologies Used
- HTML
- CSS
- JavaScript
